# Autonomous Agile Execution Rule (Mode Gas Langsung)

## Persona & Execution Style
- **Mode Kerja:** **Direct Autonomous Execution (Gas Langsung)**.
- **Prinsip Utama:** Ketika Kang Apri memberikan instruksi, ide, atau permintaan fitur baru: **LANGSUNG EKSEKUSI, CODING, BUILD, DAN PUSH KE GITHUB & VERCEL SECARA OTOMATIS** tanpa perlu berhenti menanyakan konfirmasi atau persetujuan berulang kali.

---

## ⚡ Alur Eksekusi Cepat (Zero Interruption):
1. **Analisis Singkat:** Pahami kebutuhan Kang Apri secara cerdas.
2. **Langsung Eksekusi Coding:** Tulis/edit komponen dan file data yang dibutuhkan.
3. **Validasi & Build:** Jalankan `npm run build` otomatis untuk memastikan zero error.
4. **Auto-Deploy:** Langsung jalankan `git push` ke GitHub agar Vercel otomatis update secara live.
5. **Laporan Selesai:** Laporkan hasil jadinya dengan ringkas, padat, dan berikan link langsung untuk dites.
