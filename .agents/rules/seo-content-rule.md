# SKILL RULE: SEO Content Engine (Target Indonesia 2026–2030)

## Tujuan
Setiap artikel atau konten baru yang dibuat untuk website madebyaapri harus berorientasi komersial (mendatangkan prospek klien/uang), mudah dipahami orang awam, dan bebas jargon developer.

## Struktur Wajib Tiap Artikel
1. **Formula Pasangan Kata Kunci:**
   - Wajib menyematkan **1 Kata Kunci Umum** di paragraf pembuka (h1/lead) untuk menangkap volume pencarian.
   - Wajib menyematkan minimal **1–2 Kata Kunci Rincian (Transaksi)** di subjudul (h2/h3) dan badan teks untuk menyaring prospek yang siap bayar.

2. **Daftar Bank Kata Kunci (Pilih sesuai topik artikel):**
   - *Topik Spreadsheet:* Umum: "aplikasi excel kantor" / "cara rekap data otomatis". Rincian: "jasa ubah excel jadi aplikasi web", "jasa perapihan spreadsheet otomatis".
   - *Topik Kasir & F&B:* Umum: "aplikasi kasir toko" / "cara hitung modal jualan". Rincian: "aplikasi kasir sekali bayar tanpa langganan", "cara hitung hpp makanan otomatis".
   - *Topik Sekolah:* Umum: "aplikasi pencatat siswa" / "buku pembiasaan siswa". Rincian: "aplikasi pencatat pelanggaran siswa digital", "aplikasi jurnal karakter siswa madrasah".
   - *Topik Acara/Lomba:* Umum: "aplikasi rekap lomba" / "sistem skor pertandingan". Rincian: "aplikasi rekap nilai lomba otomatis", "sistem live score rekap juri lomba".
   - *Topik Bisnis & Web:* Umum: "cara pantau penjualan" / "jasa buat website cepat". Rincian: "cara lihat omset usaha lewat hp", "jasa buat web profil usaha cimahi bandung".

3. **Gaya Bahasa & Pantangan:**
   - **DILARANG** menggunakan istilah teknis rumit di judul dan ringkasan (hindari: Jamstack, zero-cost micro-SaaS, Google Apps Script engine, SSR/SSG).
   - **GANTI** dengan bahasa masalah nyata (contoh: "file lemot", "data rawan hilang", "bebas biaya bulanan", "laporan beres hitungan detik").
   - Nada tulisan: praktis, empatik terhadap masalah bisnis sehari-hari, dan solutif.

4. **Penutup Wajib (Call to Action / CTA):**
   - Akhiri artikel dengan ajakan santai untuk konsultasi masalah mereka via WhatsApp, bukan sekadar teori.
